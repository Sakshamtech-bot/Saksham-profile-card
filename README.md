Saksham-ProfileCard — React Profile Card

A responsive glassmorphism profile card built with React 18 and Tailwind CSS.

Features

- Custom profile information and avatar
- Responsive glassmorphism UI
- Dark and light mode toggle
- Interactive Connect button
- GitHub, Twitter and LinkedIn links

Technologies

- HTML5
- React 18
- Tailwind CSS
- JavaScript (JSX)

Run Locally

1. Clone or download this repository.
2. Open "index.html" in a browser.
3. Ensure you have an internet connection for the CDN libraries.
